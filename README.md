# CampusPulse 🚀  
Smart Campus Issue Reporting & Management System

CampusPulse is an Android-based smart campus solution developed for the **Google Developer Group (GDG) Hackathon**.  
It enables students to report campus issues, employees to accept and update work status, and admins to monitor progress transparently.

---

## 🎯 Problem Statement
In many campuses, issues like infrastructure damage, cleanliness, or technical problems are reported manually, causing:
- Delays in resolution
- Lack of accountability
- No real-time tracking

---

## 💡 Solution
CampusPulse provides a **digital, role-based platform** that ensures:
- Fast issue reporting
- Clear employee responsibility
- Real-time admin monitoring
- Transparent issue lifecycle

---

## 👥 User Roles & Features

### 👨‍🎓 Student
- Report campus issues with details
- View public issues and status updates
- Track issue progress

### 👷 Employee
- View assigned and available issues
- Accept issues
- Update work status (Accepted / In Progress / Completed)

### 🧑‍💼 Admin
- View all public issues
- Monitor **Employee Work Status**
- See which employee accepted which issue
- Access reports and notifications

---

## 🛠️ Tech Stack
- **Frontend:** Android (Java, XML)
- **Backend:** Firebase Realtime Database
- **Authentication:** Firebase Auth
- **Notifications:** Firebase Cloud Messaging (FCM)
- **Architecture:** Role-based dashboards

---

## 🔥 Key Highlights
- Real-time data sync across Student, Employee & Admin
- Transparent issue assignment
- Clean and user-friendly UI
- Designed for scalability
